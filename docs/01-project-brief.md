# Project Brief

## Goal
A minimalist, memorable landing page for a flower business, built as a gift to impress the owner (a friend). It should feel personal and crafted, not like a generic template.

## v1 Scope
- **Single landing page**, no shop.
- **Language:** French only.
- **No ordering:** no prices, no "Acheter" button, no cart. Products appear only as a showcase.
- **Contact only:** social/WhatsApp/phone link for now. Online ordering may come later.
- **Style:** minimalist, with one or two signature "special" touches (see `03-creative-concepts.md`).

## Out of Scope (for now)
- E-commerce, payments (CIB / Edahabia), cart
- Arabic / RTL version
- Multi-page site, blog, admin panel

## Context
- Market: Algeria (project name "Flowers Dz")
- Audience: people looking for bouquets and arrangements, likely arriving from Instagram or word of mouth, mostly on mobile

## Success Criteria
- She loves it and feels it represents her work.
- Loads fast and looks great on mobile.
- Easy to swap in her real photos and text later.
- Easy to extend into a real shop in a later version.

## Tech (proposal, not final)
Static site: plain HTML, CSS and a little JavaScript, no framework. Deployable to any static host (GitHub Pages, Netlify, Vercel).
