# Creative Concepts

Goal: make the page special without losing the minimalist feel. Use one or two signature touches, not decoration everywhere.

## 1. Blooming on scroll
The hero starts almost empty: a single stem and the shop name. As the visitor scrolls, the stem grows and the flower opens while the text fades in around it.
- Implemented as a light line-art SVG, so it is fast and fits a minimal look.
- Works with or without real photos.
- **Status:** recommended.

## 2. Flowers as typography
The shop name is set in a very large elegant serif. Real flower photos show through the letters, or a flower replaces one letter.
- Bold and simple, entirely her own.
- Needs good photos.
- **Status:** alternative for the hero.

## 3. Seasonal colour shift
The background colour changes gently while scrolling (blush → sage → cream), like moving through a garden during the day.
- Subtle, cheap to build.
- **Status:** optional.

## 4. Hover-to-reveal gallery
Instead of a photo grid, show only the flower names in large text. Hovering a name reveals its photo, which follows the cursor. On mobile, tapping reveals it.
- Editorial, gallery-like feel.
- Needs a good mobile fallback.
- **Status:** optional.

## 5. Language of flowers
Each creation has a short poetic line about what the flower means (example: "pivoine : la timidité heureuse").
- Gives the page a voice no template has.
- Copy must be written carefully in French.
- **Status:** recommended.

## 6. Small crafted details
A tiny petal cursor, soft rounded buttons, a thin hand-drawn line between sections.
- Cheap but makes the page feel handmade.
- **Status:** optional.

## Recommendation
**1 + 5**: the blooming hero plus the poetic flower meanings. Everything else stays clean and quiet. If a bolder look is wanted, swap the hero for concept 2.
